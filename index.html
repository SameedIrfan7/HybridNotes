    How HybridNotes routes each request

    • Private or Offline → On-device only: Locks inference to Chrome's Gemini Nano so nothing leaves your device. Cloud-only tasks are refused.
    • Long Private/Offline Notes → Map-Reduce: Notes above the threshold are split into 1,200-char chunks, processed locally, and merged.
    • Deep Analyze / Translate → Cloud + Identifier Masking: Sensitive identifiers (emails, phone numbers, IDs) are masked locally before any cloud call.
    • Short Simple Tasks (< threshold) → Prefer On-device: Summarize, Quiz Me, Grammar, Title, and To-dos run locally first and fall back to cloud if needed.

    Offline AI Setup

    Enable Offline AI on This Device?

    Chrome downloads the compact Gemini Nano model (~2–4 GB) once while connected (Chrome requires ~20 GB free headroom on your drive, though only ~2–4 GB is used). After setup, notes and quizzes run 100% locally with zero internet.

    On-Device Setup Guide

    How to Enable Gemini Nano (Optional)

    You don't need Gemini Nano to use HybridNotes — Auto mode already runs on Cloud Flash-Lite with personal identifiers masked locally. Want offline on-device AI too?

    1. Use Desktop Chrome 139+ with ≥20 GB free disk space on your main drive & >3 GB GPU VRAM.
    2. Chrome 154+: Paste in Chrome's address bar, set to Enabled, then click Relaunch (on Chrome 139–153, use #prompt-api-for-gemini-nano):
      chrome://flags/#prompt-api
    3. Still unavailable? Check Broker State (disk/VRAM eligibility) or update Optimization Guide On Device Model in chrome://components:
      chrome://on-device-internals
